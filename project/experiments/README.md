# Эксперименты

- `workloads/` — манифесты приложений-нагрузок
- `datasets/` — ряды углеродной интенсивности: JSON Schema в `datasets/schemas/`, примеры Replay в `datasets/examples/` (см. `docs/research/carbon_intensity_datasets.md`)
- `scenarios/` — описания прогонов
- `results/` — краткие отчёты (крупные артефакты в `.gitignore`)
