## Контракт REST (выборочно)

- Пустой кэш: `/zones`, `/current`, `/forecast` → 503 `Status`; `/healthz` → 503 `HealthStatus`
- Неизвестная зона при заполненном снимке → 404 `Status` + `details.name`
- Stale last-good → 200 `quality: stale`, health `degraded` / `ready=true`
- `forecast: []` при mock; recorded-окно `[issuedAt, issuedAt+duration)`
- Запрещённый `/api/v1/score` → 404 mux (API-REST-03)
