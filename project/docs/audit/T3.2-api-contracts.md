## Решения T3.2

1. Время на проводе — RFC 3339 UTC (не Unix).
2. `/api/v1/healthz` = `/api/v1/health` (Kubernetes probe + SCOPE-IN-02).
3. Длительности только с суффиксом (`300s`); голое `300` запрещено.
4. Opt-in: label `enabled="true"`; иначе Score=50, не G-08.
5. `sla-deadline` — относительные секунды, не timestamp.
6. `staleWarnSeconds` / `clockSkewSeconds` внесены в args (требование T3.4).
