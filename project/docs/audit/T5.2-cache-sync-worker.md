## Структура кэша

`LocalCarbonCache` держит **один** атомарный указатель на неизменяемый `carbonSnapshot`:

```
atomic.Pointer[carbonSnapshot]
        ├── fetchedAt     // часы планировщика; возраст G-08 = now - fetchedAt
        ├── quality       // fresh | stale (худшее по зонам тика)
        ├── zones         // map[string]*ZoneCarbonState  (только IsValid=true)
        └── api           // v1alpha1.CarbonSnapshot для PreScore
```

`ZoneCarbonState` (плагин): `Zone`, `CurrentCIGCO2ePerKWh`, `Forecast`, `LastUpdated`, `IsValid`, `Record`.

- **Читатели** (`GetZoneState`, `CarbonSnapshot`): `Load()` + lookup, без mutex, без I/O. Возвращается копия записи (срез forecast копируется).
- **Писатель** (`UpdateFromService`): all-or-nothing. `GET /api/v1/zones`, затем current+forecast по каждой зоне. Ошибка HTTP/timeout → return, указатель не меняется. G-10 / FF-FUT → зона пропускается; если после валидации 0 зон → нет `Store`.
- Пустой `Load()==nil` = FF-EMPTY / Fallback-ready. `New()` **не** ждёт CDS.

Тик: сразу при старте воркера, далее `time.Ticker`. Период = `PluginArgs.RefreshIntervalSeconds` (канон стенда **30 s**). Константа `DefaultCacheSyncIntervalSeconds=10` — только если интервал в args ≤ 0 (тесты / защита). HTTP timeout канон **2 s**.

Метрики (LOCKED): `carbon_aware_sync_duration_seconds{status}`, `carbon_aware_sync_failure_total`, `carbon_aware_invalid_record_total{stage=worker}`, `carbon_aware_snapshot_age_seconds` (не выставляется, пока снимок `nil`).

## Эстафета: extension points (пользовательский T5.3)

Вход: этот кэш + [`01_architecture_ssot.md`](../ssot/01_architecture_ssot.md) §6.4 + [`failure_and_fallback_policy.md`](../ssot/failure_and_fallback_policy.md) §7 целиком + [`03_api_contracts_ssot.md`](../ssot/03_api_contracts_ssot.md) §6.

1. В `PreScore` **один** `p.cache.CarbonSnapshot()` / `Load` (`ARCH-06`). Не HTTP. Порядок: opt-in → горизонт/G-20 → hard SLA → снимок → G-08 / (2.19) или (2.23); G-09/G-10 по узлу.
2. `Score` оставить O(1) lookup `CycleState`; углеродный отказ → `Success`, не `Error` (`FF-INV-08`). **Не** вызывать `GetZoneState` из `Score`.
3. `NormalizeScore` уже делает (2.21); не переносить min-max \(S_C\).
4. Не добавлять Filter / Permit / QueueSort / Reserve.
5. Формулы — в `pkg/energy` / `pkg/carbon` / `pkg/runtime`, не в `cmd/`. Не импортировать `pkg/carbon/{provider,cache,api}` (это CDS).
6. Тесты `DOD-TEST-07` / матрица Fallback §12.

Контракты, которые нельзя переоткрывать: HTTP в горячем пути, углеродный Filter, `Score=0` как нейтраль, смешение opt-out с `fallback_total`, `Wait` на «кэш готов».
