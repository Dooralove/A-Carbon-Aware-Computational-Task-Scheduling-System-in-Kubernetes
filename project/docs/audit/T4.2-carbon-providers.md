## Контракт

Канон LOCKED — `v1alpha1.CarbonProvider`: `Current(ctx, zone, at)`, `Forecast(ctx, zone, at, horizon)`.
`at` задаёт вызывающий `Clock`, адаптер не вызывает `time.Now()` (кроме `SystemClock` внутри инжектируемых часов).

Удобная форма T4.2 (не заменяет канон):

- `GetCurrentIntensity(ctx, zone)` → `Current(..., clock.Now())`
- `GetForecast(ctx, zone, duration)` → `Forecast(..., clock.Now(), duration)`

Фабрика: `provider.NewProvider(cfg *config.Config)` / `provider.New(mode, Options)`.

## Replay Engine (`pkg/carbon/replay`)

Файл датасета (JSON schema T1.1 или CSV `zone,timestamp,carbonIntensity`) загружается целиком. Ряд по зоне сортируется; lookup — **полуинтервал** \([t_k, t_k+\Delta t)\).

| Механизм | Поведение |
| --- | --- |
| Виртуальное время | `at` усекается до **1 ms** UTC. GET **не** двигает часы |
| `LookupStep` (default) | piecewise-constant, канон T1.1 §2.4 |
| `LookupLinear` | линейная интерполяция между соседними точками (sensitivity) |
| `LoopLinear` | clamp к последней миллисекунде окна (hold last) |
| `LoopCycle` | \(t \bmod (t_{\mathrm{end}}-t_{\mathrm{start}})\) |
| Time multiplier | `ScaledClock`: \(t_{\mathrm{model}}=t_0+\mathrm{multiplier}\cdot\Delta t_{\mathrm{wall}}\) |
| Forecast `none`/`persistence` | пустой срез; persistence (2.11) делает плагин |
| Forecast `recorded` | снимок с \(\max issuedAt \le t_{\mathrm{model}}\); **без** future actuals |

Дефолт часов в процессе: `ScaledClock` от `modelStart` (replay идёт вместе со стендом). Тесты инжектят `FakeClock`.

Пример: `experiments/datasets/examples/synthetic_multizone_volatile_2h_v1.json` — ступенька north \(85\to 420\) на `10:25:00.000Z`, в `10:24:59.999Z` ещё 85.

## Live Electricity Maps

- Base URL `https://api.electricitymap.org/v3`, заголовок `auth-token`
- Таймаут HTTP (default 5 s), retry на timeout / 429 / 5xx (default 3 попытки)
- 404 → `ErrUnknownZone`; битый JSON / CI вне \([0,2000]\) → `ErrInvalidResponse`; deadline → `ErrTimeout`
- Логическая зона → `sourceZone` из `Options.SourceZones`; ключ не логируется
