## Результат

Зафиксирована размерностно замкнутая система:

1. \(P_n(u)=P_{\mathrm{idle},n}+(P_{\max,n}-P_{\mathrm{idle},n})\,\operatorname{clip}(u,0,1)\).
2. \(\widehat{P}_{\mathrm{pod}}=P_n(u^+)-P_n(u^-)\) (IDLE-NONE).
3. \(\widehat{CF}(p,n)=\eta\sum_k\widehat{P}_{\mathrm{pod}}\,\Delta t_k\,\widehat{CI}(z(n),t_k)\) с \(\eta=10^{-3}\) (часы) или \(1/(3.6\cdot10^6)\) (секунды).
4. \(S_C,S_R,S_P\in[0,1]\) с защитой \(CF_{\max}=CF_{\min}\), \(u>1\), отсутствием прогноза и hard-отсечением \(\hat T>T_{\mathrm{deadline}}\).
5. \(\operatorname{Score}(n)=100(w_C S_C+w_R S_R+w_P S_P)\), \(\sum w_i=1\).

Приёмка размерности: \([\mathrm{W}]\cdot[\mathrm{h}]\cdot[\mathrm{gCO_2e/kWh}]\cdot10^{-3}=[\mathrm{gCO_2e}]\) — формула (2.1a); эталон 14.2 даёт \(3{,}6\,\mathrm{gCO_2e}\) в обеих единицах времени.
